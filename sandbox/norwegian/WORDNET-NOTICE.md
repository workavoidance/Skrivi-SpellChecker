# Norsk ordvev attribution

This experiment uses semantic relations derived from **Norwegian WordNet – Bokmål (Norsk ordvev), version 1.1.2**, published by the National Library of Norway / Språkbanken. Dataset page and download: https://data.norge.no/en/datasets/f479d8ff-03aa-3af5-a8d5-03854a9ba190/norwegian-wordnet-bokmal

The public dataset catalogue identifies the distribution as CC BY 4.0: https://creativecommons.org/licenses/by/4.0/

The source archive also contains the DanNet 1.0 licence notice. Norsk ordvev's core structure is based on DanNet, created by the University of Copenhagen and the Society for Danish Language and Literature. The source notice must be retained with distributed copies and is preserved by this attribution file.

Skrivi builds a reduced lookup index that contains selected word forms and semantic relations. The UI identifies automatic entries as coming from Norsk ordvev and links to the dataset page.
