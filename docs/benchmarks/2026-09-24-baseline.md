# Recovered Norwegian baseline — 24 September 2026

The unchanged default Nuspell + NorBERT3 Small context mode outperformed spelling-only and ranking-only modes on all three recovered suites. This supports retaining the small-model hybrid; the run does not establish performance on unseen dyslexic writing or justify a larger model.

387 cases, 277 labelled correction targets, three modes: **1,161 checks completed, zero failures**. All results are newly measured after recovery and relocation. No model, dictionary, application threshold or UI was changed. No downloads, audio generation or cloud inference were used. Private writing and per-token traces remain in ignored local results.

## Authentic local paragraph

The existing key contains **16 scored targets and seven unscored positions**. Nuspell alone detects 6 and shows the intended answer in the top three for 1. Ranking-only still detects 6, but succeeds on 5. Default context detects 12, has the intended candidate for 15, and succeeds on 11; it adds one non-target flag. Of five failures, four are not flagged and one is flagged with the answer present but outside the displayed three. Unresolved wording and boundary operations remain excluded; this is not a claim that the whole paragraph has only 16 problems.

## Three choices versus five

A counterfactual from the saved scores preserves current detection and the known-word gap threshold (>4). Default top-five coverage would be **89/105, 70/72, 100/100**, versus 87/105, 70/72, 100/100 for three. The authentic paragraph rises from **11/16 to 12/16**. This is not a five-option user test and does not justify adding choice burden by default. Unrestricted ranked-pool coverage would misleadingly count answers on unflagged words.

Ranking and context each gained targets without losing a previously successful top-three target in this particular run. Medians exclude lazy model loading and word-help lookup, not a cold-start latency guarantee. Python and model libraries were already warm for later modes. Timing repetitions were not warranted for this diagnostic question.

## Recommendations

1. Keep the current small-model hybrid and three default choices. There is no new evidence here requiring a bigger model.
2. Treat deciding to flag valid-word errors as the next scoring experiment. Inspect the saved misses, then use separate paired correct/incorrect examples before changing thresholds. Do not tune to make this paragraph pass.
3. Improve actual definition/example coverage as a separate product task. Integrate a locally licensed dictionary with inflection-to-lemma lookup and preserve source/sense information; confirm distribution rights before bundling. Synonyms are a fallback, not a measured substitute for explanations.
4. Adjudicate clean-text flags, especially traditional-dictionary acceptance failures, before expanding context sensitivity. Candidate rescue remains needed, but only four labelled targets lack the intended candidate in this run.
